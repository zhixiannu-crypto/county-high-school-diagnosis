# 高中多语种升学增量分析系统 V1.3：数据与测算说明

网站使用学校上传的本次考试成绩和学校自行填写的本科、重本参考线。省份仅用于基本信息，不参与达线计算。网站不读取省级高考分数线数据库，也不保存上传文件、报告或名单。

每次只分析同一场考试、同一年级、同一满分制度的逐名成绩。文件若包含不可合并的多个考试或年级，提示分开上传。英语成绩有效且可识别的记录进入英语学情分析；总分有效的记录进入达线率分母。总分或英语满分缺失时由用户填写，系统不假定750分或150分。

英语薄弱：若学校填写英语单科薄弱参考线，英语成绩低于该线者入选；否则按英语得分率低于60%，或者在至少30名学生的同场考试中位于后25%且得分率低于80%入选。英语明显偏科：同一学科组合中至少30名学生、学生有至少两门其他学科成绩时，计算英语与各其他学科成绩的百分位。英语百分位不高于50%，且其他学科平均百分位高出英语至少25个百分点者入选。其他学科不足时不判断偏科。

历史参考情景使用内置的2026年聚合外语成绩差值中位数。先把本次英语成绩按满分比例换算到历史模型的150分量尺，匹配历史分组，再把参考差值按本次英语满分比例换回；成绩变化量受英语满分和考试总分满分限制。未匹配历史分组的学生不假定增分，不计入模拟新增。该差值不是改学多语种的因果净效应。

模拟总分＝当前总分＋受满分限制的外语成绩变化量。当前低于学校本次参考线、模拟后达到该线者为冲线候选；原本已达线者不计入新增。当前达线率＝当前达线人数÷有效英语和总分人数；模拟达线率＝模拟达线人数÷同一人数；提升用百分点表示。本科和重本冲线名单可能有交集，不能相加。

名单仅在用户主动确认后于浏览器本地生成。学生姓名、学号和班级仅取自原表；身份不足以区分学生时阻止导出。报告和PDF只使用汇总统计，不展示学生实名明细。刷新或关闭页面后，当前成绩与名单从页面内存清除。
