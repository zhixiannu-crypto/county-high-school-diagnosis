# 数据处理与统计口径 · V1.0

## 1. 数据来源与适用范围

学校当前数据由使用者提供，在浏览器内存中处理。历史模型仅使用用户提供的2026年历史表，构建一次性分组汇总，不发布原始工作簿、学生记录、学校列表或录取院校字段。系统不区分日语、俄语、西班牙语效果，因为历史表没有独立语种标签。

历史表有8,666条记录；原始英语与小语种成绩同时处于(0,150]的有效配对7,861条，排除805条。有效配对原始英语均值46.3401分，小语种均值91.8005分，差值均值45.4603分，中位数46分。零分可能是缺失占位，全部从历史配对中排除。原表没有可靠身份字段，不能把相同成绩记录贸然删除，也不能证明7,861条记录均为独立学生。

历史基础组采用[0,30)、[30,60)、[60,90)、[90,120)、[120,151)。每组发布样本数、均值、中位数、四分位数与范围。少于30条时停用，不发布该组精确参数。分位数采用排序后的线性插值((n−1)×p)。120–150分组没有样本，禁止外推。

原始英语测试日期、考试难度及满分口径缺少独立佐证，历史模型暂按150分制解释。前后差值包含学习阶段、教学条件、考试难度与样本选择等影响，**不是相对于继续学习英语的因果净增益**。这些差值只能构造清楚标注假设的参考情景。

## 2. 导入、清洗与隐私

- 本地SheetJS CE 0.20.3解析.xlsx、BIFF .xls、UTF-8或GB18030 CSV；禁止宏执行，不读取外链数据。
- 在前40行寻找表头，支持常见双行表头和合并表头；多个候选字段要求确认，不擅自选择。无法识别的工作表跳过并提示，不保证任意复杂排版均可自动识别。
- 数字文本经NFKC规范化后解析；空白、“缺考”“—”等不作为零分。
- 零分默认待核实；只有输入中“零分已核实”字段明确为“是/已核实/true/1”时，才作为真实0分。禁止默认为真实成绩。
- 英语超出明确满分范围排除。未知满分时150分仅作为保守异常上限，**不是**确认该考试采用150分制；不会因此开放情景测算。未知总分时900仅为异常检查上限。
- 总分为空、未核实零分、低于英语或超过满分时保留英语分析，但排除该条达线统计。
- 其他学科异常仅移除该学科；语文/数学上限150，单门其他学科100，理综/文综300。特殊单科满分制未实现自动校准；超出这些上限的数据须先明确口径，当前按不可靠处理。综合科与其细分科不重复计入。
- 公式成绩不采用缓存结果，避免将过期计算缓存当成真实成绩；请在Excel中核对并粘贴为数值后上传。
- 同一统计组同编号同成绩保留一次；同编号成绩冲突的全部记录排除。姓名不能单独当作可靠标识。没有编号时同分记录保留并提示疑似重复，仅称“记录”，不保证独立人数。
- 姓名、身份证、电话、地址和班级内部标识不进入分析输出；学号仅在Worker内临时映射为匿名整数，用于当前运行中的去重。主线程不接收原始编号。
- 无日志明细、外部分析脚本、云端上传或持久化浏览器存储。清除、刷新或关闭后不保留数据；页面与公开参数的正常HTTP加载不包含上传成绩。
- 单文件10MB，解压体积60MB，最多30表、合计50,000条附近的行数及128列，Worker处理25秒超时自动终止。异常压缩结构拒绝解析。

## 3. 统计分组

按学校、省份、年级、考试名称、年份、招生类别、选科组合、英语满分、总分满分与总分口径分组。考试未知时以工作表隔离，不混排。不同考试出现的同一个人可以在各考试分别分析，但报告不合计为全校独立学生人数。

同一个多表文件可含多个统计组，页面自动处理并提供当前组切换；打印当前组。完整数据通常5页，无法跨线测算时3页，仅汇总数据1页。多组分别打印，不能将每组人数相加为全校人数。

## 4. 英语薄弱与相对偏科

### 英语薄弱

英语得分率<60%，或同组有效英语记录≥30时，英语百分位≤25%且得分率<80%。满分未知时，只能识别本组百分位≤25%的相对薄弱记录，且必须≥30条。全部同分时不使用相对规则。n=0不显示群体人数。

### 英语明显偏科候选

同一统计组内，再按“实际具备的其他学科字段集合”建立可比样本面板。面板至少30条，其他学科至少2门。对每门学科计算同分中间秩百分位：中间秩从0开始除以(n−1)。其他学科百分位取等权均值；当英语百分位≤50%，且其他学科平均百分位−英语百分位≥25个百分点时标记明显偏科候选。

这是一套固定、可复核的筛选规则，不是经过独立样本验证的教育诊断量表。报告显示可判定样本数和无法判定样本数；未判定不等于不偏科。偏科比例的分母是可判定面板样本数，英语薄弱比例的分母是全部有效英语记录数。

薄弱与偏科集合允许交集。结构图采用互斥四分区，不重复相加。只有英语/英语＋总分时不假称已经识别相对偏科。

## 5. 官方线匹配与考试可比性

仅启用data/cutoffs-2026.json内status=verified且招生类别完全匹配的2026条目。每条线保留准确名称和官方URL；普通类一段线不改称本科录取线，特控线不改称重点本科线。

英语满分、总分上限、考试、年级、年份及总分计分口径必须已知。总分满分须与该省记录一致；未知或不匹配不计算跨线。学校须确认总分包含与本省高考相同的原始分/赋分口径。系统不做线性缩放或难度等值。

非2026高考本次考试全部标注为“相对于2026年官方分数线的参考情景”；不能称为预计高考录取人数。海南综合标准分不能加减原始英语差值，禁用本模型。艺术体育、民族/专项、春季高考等未完整建模类别不强行匹配普通类。

## 6. 临界与单一历史差值情景

临界区间=[线−30，线＋10)，包含线下30分边界，不包含线上10分边界。

候选集合=英语薄弱 ∪ 英语明显偏科。具备可靠总分的候选记录匹配其原始英语基础历史组，情景差值取组内中位数，允许负值。非候选学生总分保持不变。

```text
模拟英语 = min(英语满分, max(0, 当前英语 + 组内差值中位数))
模拟总分 = min(总分满分, max(0, 当前总分 + 模拟英语 − 当前英语))
当前人数 = count(当前总分 ≥ 参考线)
模拟人数 = count(模拟总分 ≥ 参考线)
首次新增 = count(当前总分 < 参考线 且 模拟总分 ≥ 参考线)
模拟掉线 = count(当前总分 ≥ 参考线 且 模拟总分 < 参考线)
N = 同时具备有效英语与可靠总分的本组记录数
当前率 = 当前人数 / N × 100%
模拟率 = 模拟人数 / N × 100%
百分点变化 = (模拟人数 − 当前人数) / N × 100
```

有候选记录缺少可靠历史分组时，仅输出当前达线和临界统计，整体模拟结果显示无法测算。数据不足不以0代替。不同参考线的新增群体可能重叠，不相加。模拟新增与净人数变化在出现负差值时不一定相同，报告另列掉线人数。

## 7. 文案与维护

固定规则与条件文案组合，无AI接口；覆盖薄弱多/少、明显偏科、整体基础弱、临界聚集、缺少总分、缺少学科、数据质量与口径不可比等情况。没有证据时不输出开班建议、升学承诺或营销文案。

规则在src/rules.js，统计在analysis.js，清洗在cleaning.js，文案在narrative.js，报告在report.js。修改阈值后必须更新规则版本、说明和测试。历史聚合脚本scripts/build-history.py仅供线下维护，不是网站后端，读取真实附件必须由有权限人员在本地执行；只提交汇总JSON。

静态公开资源无法对用户隐藏汇总参数。当前已完成数据结构、清洗规则、分组样本和参数计算审核；集团是否允许公开这些汇总参数，仍由发布方按自身商业保密规则确认。
