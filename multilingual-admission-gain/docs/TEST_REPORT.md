# 验证记录 · V1.0

验证环境：2026-10-20，本机Node.js 24.19.0。运行命令：`npm test`。测试不调用远程服务，不使用真实学生明细作为发布测试夹具。

## 已完成的自动验证

35项自动化测试通过（32项核心/导入/配置测试，3项实际Worker流程与依赖完整性测试）。覆盖：

- 文本数字、空白、非法数字、零分确认、同分百分位、表头偏移、双行表头与字段歧义。
- 可靠编号精确去重、同编号冲突排除、无编号同分记录保留。
- 固定薄弱规则、明确偏科数量、无其他学科不判断偏科、不同学科面板不混算。
- 参考线临界区间边界、当前达线、首次新增、不重复计算已达线学生、同一分母、百分点。
- 负历史差值造成的模拟掉线、英语与总分满分边界、历史样本不足停止精确模拟。
- 缺少总分、类别不符、计分口径未知、满分制度不符、海南标准分的降级处理。
- 学校模拟考试的参考情景标签；不同年级、考试、类别隔离。
- 原始历史表统计复核为8,666条、有效配对7,861条、排除805条，分组样本数可加总复核。
- 31省配置完整性、2026年份、来源URL和分值边界。
- 10场景虚构数据：较多偏科、整体均衡、临界集中、英语＋总分、仅英语、缺失重复异常、多年级多考试、缺少学校省份、官方类别不可匹配、仅汇总数据。
- 外语字段语种不明必须确认，公式缓存成绩不采用，输出HTML转义，不展示原始编号。
- 真正BIFF .xls文件解析、损坏ZIP拒绝。
- 导出的10工作表.xlsx通过实际解析Worker的读取/确认/提取消息流程，获得10个成绩统计组＋1个汇总组；源匿名编号不进入输出。
- 600人CSV通过实际Worker消息流程，得到可测算的600条有效记录。
- 本地SheetJS包SHA-256校验；生产自有代码无持久化存储、成绩POST发送、分析日志明细代码。

“Worker测试”在Node.js中适配消息通道执行生产Worker代码，验证解析协议与计算；不等同于真实浏览器端到端验收。

## 文件与视觉检查

已用表格渲染器渲染并检查10个测试工作表的标题、元数据、表头与首批数据；导出的工作簿由独立解析器和实际Worker重新读取验证。来源表未改动，交付目录不包含真实历史原始工作簿。

主站本机静态服务HTTP读取成功，模块语法检查通过。报告为SVG矢量图，所有图表和正文来自同一计算对象；同输入重复输出一致。浏览器打印按钮实际调用`window.print()`，并提供A4样式。

- 手机实际布局、键盘操作和浏览器控制台无异常。
